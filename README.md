# 🤖 ChatX AI

ChatX AI is a simple and interactive AI chatbot built using **Python, Streamlit, and Generative AI**.

It provides a clean chat interface where users can interact with an AI model and get real-time responses.

## 🚀 Features

- 💬 Interactive AI chat interface
- 🤖 Generative AI-powered responses
- 🧠 Maintains conversation during the session
- 🎨 Simple and user-friendly UI
- ⚡ Fast response generation
- 🔐 API key based authentication
- 📱 Responsive Streamlit interface

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Google Gemini API**
- **Generative AI**
- **Git & GitHub**
